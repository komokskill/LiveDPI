# LiveDPI

**Modern network traffic management and DPI bypass toolkit.**

LiveDPI — современное приложение для Windows, объединяющее инструменты управления сетевым трафиком, обхода DPI и настройки сетевых соединений в едином удобном интерфейсе.

Проект создан с упором на производительность, гибкость настройки, автоматизацию и простоту использования.

### Основные возможности

- **DPI Engine** — обработка и модификация сетевого трафика с использованием WinDivert.
- **Auto Configuration** — автоматический подбор и применение сетевых конфигураций.
- **Smart DNS** — интеллектуальная обработка DNS-запросов и интеграция с прокси-механизмами.
- **SNI Proxy** — поддержка проксирования соединений с учётом TLS SNI.
- **Telegram** — отдельный модуль сетевой интеграции для Telegram.
- **Module Manager** — централизованное управление сетевыми модулями.
- **Profiles** — сохранение, переключение и управление конфигурациями.
- **Monitoring** — мониторинг сетевой активности, скорости соединения, задержки и потерь пакетов.

### Интерфейс

LiveDPI использует современный тёмный интерфейс с минималистичным дизайном, визуализацией сетевой активности и централизованным управлением всеми компонентами.

### Цели проекта

- Объединить необходимые сетевые инструменты в одном приложении.
- Обеспечить гибкую настройку сетевых компонентов.
- Минимизировать влияние на производительность системы.
- Сделать управление сетевыми конфигурациями доступным и понятным.
- Развивать модульную архитектуру с возможностью расширения.

### Статус разработки

LiveDPI находится в активной разработке. Возможности, совместимость и стабильность отдельных модулей могут меняться.

### Open Source

Проект развивается с открытым исходным кодом. Предложения по улучшению, сообщения об ошибках и участие в разработке приветствуются.
